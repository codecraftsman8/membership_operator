# Python Membership Operators (`in` and `not in`)

This repository explains Python Membership Operators with simple examples for beginners.

### Operators Covered
- **`in`** – Returns `True` if a specified value exists in a sequence.
- **`not in`** – Returns `True` if a specified value does not exist in a sequence.

### Topics Included
- Membership operators in Python
- Checking elements in strings and lists
- Using membership operators with `for` loops
- Practical examples with output

### Who Is This For?
Python beginners who want to understand membership operators through simple, practical examples.
